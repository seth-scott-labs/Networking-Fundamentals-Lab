# Networking Fundamentals Lab

## Overview

Planned hands-on networking lab focused on understanding basic network configuration, connectivity, addressing, and troubleshooting.

This project will document practical networking exercises performed on a Windows system as part of my cybersecurity education.

The goal is to build foundational networking knowledge through hands-on testing, observation, and documentation.

---

## Lab Objectives

This lab will cover:

- IPv4 addressing
- Private and public IP addresses
- Default gateways
- DNS servers
- Network configuration
- Connectivity testing
- DNS resolution
- Basic routing concepts
- Network troubleshooting

---

## Planned Exercises

### 1. Network Configuration

Identify and document relevant network configuration information using Windows tools.

Topics include:

- IPv4 address
- Subnet mask
- Default gateway
- DNS configuration
- Network adapter information

Sensitive network information will be excluded from the public documentation.

### 2. Connectivity Testing

Use common networking commands to test connectivity and investigate network behavior.

Planned commands include:
```
ipconfig
ping
tracert
nslookup
```
### 3. IPv4 Fundamentals

Investigate:

- IPv4 addresses
- Private address ranges
- Public IP addresses
- Subnet masks
- Network and host portions
- Default gateways

### 4. DNS

Investigate how DNS resolution works and use ```nslookup``` to examine DNS queries.

### 5. Basic Troubleshooting

Practice a structured troubleshooting process:

1. Identify the connectivity problem
2. Check local network configuration
3. Test the local network connection
4. Test gateway connectivity
5. Test external connectivity
6. Test DNS resolution
7. Trace network routing
8. Identify the likely source of the problem
9. Document the findings

## Security & Privacy

Public documentation will not include sensitive network information.

The following will be excluded or redacted:

- Public IP addresses
- MAC addresses
- Wi-Fi SSIDs
- Router information
- Private network details
- Passwords
- Device identifiers
- Personal usernames
- Other identifying network information

Screenshots will be reviewed and redacted before being added to the repository.
